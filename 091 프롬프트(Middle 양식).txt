당신은 최고 수준의 프론트엔드 엔지니어이자 QA 자동화 전문가입니다. 아래의 절차와 제약 사항을 엄격하게 준수하여 작업을 수행하십시오.

## 1. 사전 준비 및 가이드라인 숙지 (필수)
- 작업 시작 전, 반드시 `'081 가이드(Middle 양식).md'` 파일을 읽으십시오.
- 현재 상황에 맞는 섹션을 찾아, **첫 줄부터 'STOP STOP - 읽기 중단!' 마커가 있는 곳까지만** 정독하십시오.
- 가이드 문서를 완벽히 이해하고, 과거의 비슷한 실패 사례를 분석하여 이번 작업의 우회 및 해결 방안을 도출하십시오.

## 2. 작업 가능 여부 판단 (진행/중단)
- 위 가이드를 준수하며 아래 명시된 4가지 개선사항에 대해 **'기존 기능을 100% 보호하는 무결성 보증 리팩토링'**이 가능한지 먼저 판단하십시오.
- **진행 가능:** 화면에 `[OK]`를 출력하고 즉시 3번 항목의 작업을 시작하십시오.
- **진행 불가:** 화면에 `[NO]`를 출력하고 사유를 설명한 뒤 즉시 모든 작업을 중단하십시오.

## 3. 리팩토링 핵심 제약 사항
- 최종 결과물을 단독 HTML 파일로 저장하여 실행했을 때, 원본 UI 및 기능과 **완벽하게 동일하게** 구현되어야 합니다.
- 아래의 모든 작업은 '모바일 세로 모드 최적화'를 목표로 하며, 기존의 다른 기능에 어떠한 부작용(Side-effect)도 일으켜서는 안 됩니다.

## 4. 세부 개선 사항 (모바일 세로 모드 최적화)
**① '정산' 모달 내 상세 테이블 스와이프 버그 수정**
- 대상: 월별/분기별/연도별 팝업창(모달) 내부의 '상세 테이블' 영역
- 현상: 손가락으로 좌/우 제스처(스크롤) 시 화면이 이동하지 않음.
- 요구사항: 상세 테이블 상단에 위치한 '분석 카드' 영역에서 좌/우 스와이프가 작동하는 것과 **완벽히 동일한 원리 및 체감**으로 상세 테이블에서도 좌/우 스크롤이 정상 작동하도록 수정하십시오.

**② '일정' 간트차트 작업목록 핀치 줌(확대/축소) 개선**
- 대상: 간트차트 작업목록(좌측) 영역 (일반보기 / 전체보기 모드 모두 적용)
- 현상: 두 손가락으로 화면 줌 인/아웃(Pinch-to-zoom) 시 화면이 비정상적으로 튕기는 현상 발생.
- 요구사항: 현재의 기능은 그대로 유지하면서, 화면 튕김 없이 부드럽게 두 손가락 확대/축소가 가능하도록 터치 이벤트를 최적화하십시오.

**③ '일정' 간트차트 작업목록 너비 조절(Resizing) 기능 추가**
- 대상: 간트차트 작업목록(좌측) 영역
- 요구사항: 기존 기능 유지 하에, 작업목록 제일 우측에 있는 **'진행률' 열의 우측 외곽 끝선**을 손가락으로 터치 및 드래그(Drag)하여 작업목록 전체 영역의 폭(Width)을 자유롭게 넓히고 좁힐 수 있도록 구현하십시오.

**④ '일정' 간트차트 '전체보기' 모달 내 이중 클릭 버그 방지**
- 대상: 간트차트 작업목록(좌측) 영역 내 '명칭' 옆의 '전체보기' 표시 기호
- 현상: '전체보기' 팝업창(모달) 내부에서 해당 기호가 이중 클릭되어 시스템 오류가 발생함.
- 요구사항: 팝업창이 열린 상태에서는 해당 기호가 중복 클릭되지 않도록 이벤트 방어(Debounce 또는 Disabled 처리 등) 로직을 추가하여 오류를 원천 차단하십시오.

**⑤ '일정' 간트차트 '범례' 컨테이너의 필터링 클릭시 정렬 :
- 대상:  '이번주(##건)' , '다음주(##건)' 
- 현상:  간트차트 작업목록(좌측) 영역의 해당 목록 표시시 요일별로 정렬이 되지 않고 있어 요일(월,화,수,목,금,토,일)을 찾기가 어려움
- 요구사항: 간트차트 작업목록(좌측) 영역의 대상 목록의 정렬을 (월,화,수,목,금,토,일) 순서로 자동 정렬이 되어 표시 되도록 해주세요.


## 5. 검증 및 추가 성능 최적화 (Playwright CLI)
- 리팩토링 로직 작성이 완료되면, 즉시 **Playwright CLI 스킬**을 사용하여 테스트를 수행하십시오.
혹시 **Playwright CLI 스킬** 가 없으면 웹서핑 해서 다운로딩후 진행 테스트를 수행하십시오.
- 위 4가지 개선 부분의 정상 작동 여부 및 렌더링 성능 저하가 없는지 엄격히 검증하십시오.
- 검증 과정에서 추가로 성능 개선이 가능한 부분(DOM 리페인트 최소화 등)이 발견되면 **즉시 코드를 수정하여 성능을 개선**하십시오.

## 6. 가이드 문서 자동 업데이트 (Self-Learning)
- 작업 진행 중 오류가 발생하여 실패하고 이를 다시 해결하는 과정을 겪었다면, 해당 문제의 원인과 우회/해결 방법을 정리하십시오.
- 정리된 내용을 바탕으로 `'081 가이드(Middle 양식).md'` 문서의 실패 사례 섹션을 **직접 업데이트(기록)** 하여 향후 동일한 실수가 반복되지 않도록 조치하십시오.

```javascript

 * 🚀 안티 그래비티 자동 클릭 + 터미널 자동 숨김 매크로(Accept , Always Allow , Accept all , Allow Once)

//////////

/**
 * 🚀 안티 그래비티 비침투성 자동 클릭 매크로
 * 특징: 터미널 강제 은폐(CSS Injection) + 즉각적 포커스 복구

///////////////

(function() {
    if (window.antiGravityFinalLock) return;
    window.antiGravityFinalLock = true;

    let isProcessing = false;
    const COOL_DOWN = 1500; 

    function eliminateTargets(root) {
        if (isProcessing) return;

        // 1. 타겟 단어 리스트 (불필요한 단어 제외)
        const targetTexts = ['allow', 'accept all', 'always allow', 'run', 'yes', 'confirm', 'accept', 'approve', 'ok'];
        // 2. 제외할 단어 (예: 상태 메시지 'running...')
        const excludeTexts = ['running', 'loading', 'processing', 'wait'];

        const candidates = root.querySelectorAll('button, [role="button"], .monaco-button, .action-label, a, div, span');

        for (const el of candidates) {
            if (el.shadowRoot) eliminateTargets(el.shadowRoot);

            if (el.dataset.autoClicked === "true") continue;

            const content = (el.innerText || "").toLowerCase().trim();
            if (!content) continue;

            // [로직 강화] 제외 단어가 포함되어 있으면 무시
            if (excludeTexts.some(ex => content.includes(ex))) continue;

            // [로직 강화] 타겟 단어 매칭
            const isMatch = targetTexts.some(t => {
                if (t === 'accept all') return content.includes('accept') && content.includes('all');
                if (t === 'ok') return content === 'ok' || content === 'okay';
                return content === t || (content.includes(t) && content.length < 15); // 너무 긴 문장은 제외
            });

            if (isMatch && el.offsetWidth > 0 && el.offsetHeight > 0) {
                // [핵심] 실제 클릭 가능한 요소인지 스타일 검사
                const style = window.getComputedStyle(el);
                const isClickable = style.cursor === 'pointer' || 
                                   el.tagName === 'BUTTON' || 
                                   el.getAttribute('role') === 'button' ||
                                   el.classList.contains('monaco-button');

                if (!isClickable) continue;

                isProcessing = true;
                el.dataset.autoClicked = "true";
                
                const originalBg = el.style.backgroundColor;
                el.style.backgroundColor = "#ff0000"; 

                console.log(`[🎯 TARGET FOUND] "${content}" 클릭 실행`);

                setTimeout(() => {
                    try {
                        // 실제 클릭 이벤트 발생
                        el.click();
                        ['mousedown', 'mouseup', 'click'].forEach(evt => {
                            el.dispatchEvent(new MouseEvent(evt, {
                                bubbles: true, cancelable: true, view: window, buttons: 1
                            }));
                        });
                        console.log(`[✅ SUCCESS] "${content}" 처리 완료`);
                    } catch (err) {
                        console.error("[❌ ERROR] 클릭 실패:", err);
                        el.dataset.autoClicked = "false";
                    } finally {
                        setTimeout(() => {
                            isProcessing = false;
                            el.style.backgroundColor = originalBg;
                        }, COOL_DOWN);
                    }
                }, 100);
                break; 
            }
        }
    }

    const globalObserver = setInterval(() => {
        try { eliminateTargets(document); } catch (e) { isProcessing = false; }
    }, 1000);

    window.killFinalMacro = () => {
        clearInterval(globalObserver);
        window.antiGravityFinalLock = false;
        console.log("🛑 매크로 종료");
    };

    console.log("🚀 [v5.0 정밀 타겟팅] 매크로 가동 시작.");
})();
